### MBS

在介绍2008年世界经济危机前，我们先介绍一类特殊的资产：**抵押贷款支持证券**（Mortgage-Backed Securities，MBS）。我们看下边这个例子：

1. 张三买房：张三想买一套100万的房子，自己付了20万首付，向**工商银行**借了80万，期限30年，年利率5%。每个月，张三要还工商银行约**4300元**（本金+利息）。

2. 银行的困境：工商银行同时给**1000个张三**发放了类似的贷款，总共放出去**8亿元**。问题在于这8亿元被"锁死"在贷款里，要等30年才能慢慢收回来。银行的钱不够用了，没办法再给新客户放贷。
3. 打包出售：工商银行灵机一动，把这1000笔贷款**打包**，卖给一个专门的机构（SPV）。SPV把这个"大包"切成**8000份证券**，每份面值10万元，向社会上的投资者出售。工商银行立刻拿回了现金，可以继续放新贷款了。
4. 李四买证券。李四是一个投资者，买了1份MBS，花了10万元。从此以后，1000个张三每月还款的钱，按比例流向李四：每月大约收到**430元**左右（利息为主，还有少量本金）。这就是李四的**投资收益**——本质上，他把钱借给了全国各地素不相识的购房者。

但上述过程存在很大的风险：

| 情况                             | 对李四的影响                                   |
| -------------------------------- | ---------------------------------------------- |
| 张三们正常还款                   | 每月稳定收到430元，皆大欢喜                    |
| 利率大降，张三提前还清贷款再融资 | 李四提前收回本金，但找不到同样高收益的地方投资 |
| 经济危机，张三们大量违约         | 李四的MBS价值暴跌，血本无归                    |

2008年金融危机，正是第三种情况——大量购房者无力还款，MBS价值归零，持有大量MBS的金融机构纷纷破产。

一些SPV机构：

| 机构       | 全称                                | 特点                                       |
| ---------- | ----------------------------------- | ------------------------------------------ |
| **房利美** | Fannie Mae（联邦国家抵押贷款协会）  | 1938年成立，政府背景，发行量最大           |
| **房地美** | Freddie Mac（联邦住房贷款抵押公司） | 1970年成立，与房利美并列                   |
| **吉利美** | Ginnie Mae（政府国家抵押贷款协会）  | 完全政府所有，专门针对FHA/VA贷款，信用最高 |

### 经济危机的背景

2000年代早期，全球处于一个 **极低利率时代**。低利率降低了购房贷款成本，使家庭更容易借更多钱买房。抵押贷款利率下降以后，住房需求上升，进而推动房价上涨。美国、爱尔兰、西班牙等国家都出现了房地产价格繁荣和住房建设繁荣。

美国问题的特殊之处在于出现了大量 **sub-prime mortgage lending**，即次级抵押贷款。所谓次级贷款，是指借款人信用记录较差、还款能力较弱，但仍然获得住房贷款。正常情况下，这类贷款风险很高，银行应该谨慎发放。但在当时，银行和金融机构通过 **securitisation**，也就是证券化，把这些抵押贷款打包成金融证券出售给投资者。

既然次贷MBS有风险，为什么银行和投资者还愿意购买？

1. 房价上涨预期：金融机构相信房价会继续上涨。即使借款人违约，银行或投资者也认为可以收回房屋并出售，由于房价上涨，出售房屋仍能覆盖贷款本金。因此，他们承认违约概率较高，但低估了实际损失风险。
2. 分散化幻觉：他们相信 **地理分散化** 能够降低风险。MBS背后对应的是美国不同地区的住房贷款。过去美国确实出现过地区性房价下跌，但较少出现全国范围内房价同时下跌。因此，投资者误以为将不同地区贷款打包后，风险已经被充分分散。
3. 评级依赖：评级机构给许多MBS很高的信用评级，甚至很多由次级抵押贷款支持的证券也获得了AAA评级。AAA评级通常意味着极低违约风险，因此这些资产看起来像是安全资产。
4. 欺诈问题。许多次贷申请材料中存在收入、房产价值、自住情况、第二抵押权等方面的虚假或错误信息。也就是说，贷款基础资产本身的质量比表面上更差。
5. 宏观稳定幻觉：当时人们处在所谓 **Great Moderation** 的观念中。自1980年代中期以来，宏观经济波动明显下降，许多人相信经济已经进入低波动、低风险时代。因此，他们低估了宏观层面同时出现大规模违约和房价下跌的可能性。

次级抵押贷款发放在2005年达到高峰。到2006年，随着抵押贷款利率上升，以及近期贷款质量较差的证据逐渐显现，融资繁荣结束。当融资繁荣停止时，房价已经偏离基本面。于是从2006年春季开始，美国房价先是缓慢下降，随后加速下跌。房价下跌带来两个后果：一是很多借款人无法继续还款；二是很多人进入 **negative equity**，即负资产状态。所谓负资产，是指房屋市场价值低于未偿还贷款本金。

美国许多州存在 **non-recourse mortgages**，即无追索权抵押贷款。在这种制度下，借款人可以把房子交还给银行，不再继续承担贷款债务，这被形象地称为 **jingle mail**。如果房屋卖价低于贷款金额，损失由银行或MBS投资者承担。即使在有追索权的州，银行追讨债务的法律过程也通常缓慢且昂贵。因此，原本MBS应该依赖抵押贷款产生稳定还款现金流，但现在大量抵押贷款变成了“清算资产”的过程：服务机构收回房子，再尽可能高价出售。结果是违约潮迅速出现。

到2008年，投资者开始意识到全球银行体系的风险远比之前想象的大。

1. **资产风险暴露**。许多全球性银行，尤其是欧洲银行，购买了大量MBS。有些原本负责出售MBS的银行，到2008年也发现自己持有了大量自己发行或相关的产品。除此之外，很多大型银行还参与大量自营交易，也就是用自己的资产负债表进行市场投资。在市场下跌时，这些交易也可能产生巨额损失。
2. **资本和融资脆弱性**。大型银行普遍杠杆率很高，资本不足以吸收大规模损失。与此同时，许多银行高度依赖短期非存款融资。一旦短期融资市场不愿意继续借钱给银行，银行就会遭遇流动性危机。

我们之前已经介绍给两类问题 **solvency problem** 和 **liquidity problem**：

| 问题类型     | 含义                                                   | 在危机中的表现                  |
| ------------ | ------------------------------------------------------ | ------------------------------- |
| 偿付能力问题 | 资产价值低于负债，资本被亏损侵蚀                       | MBS损失、交易资产损失、资本不足 |
| 流动性问题   | 即使资产未必完全不够，但短期内借不到钱、还不上到期债务 | 短期批发融资撤离、非存款挤兑    |

2008年的危险在于，两类问题叠加：投资者担心银行资不抵债，于是不愿意继续融资；融资断裂又迫使银行抛售资产，进一步恶化偿付能力。

危机的早期迹象在2007年8月已经出现。当时市场开始担心次贷MBS损失会影响不同金融机构。从2007年8月起，美联储、欧洲央行和英格兰银行都大幅增加了流动性供给操作，因为一些脆弱银行开始失去融资。当时政策主要解决的是 **liquidity problem**，即给银行提供流动性；但对于危机核心的 **solvency problem**，也就是大型国际银行是否资本不足、是否真正资不抵债，政策回应很有限。

到2008年9月，美国政府认为此前的救助已经引起政治争议，并且可能树立了不好的先例，也就是市场会预期政府总会救助大型金融机构。于是，当Lehman Brothers遭遇类似Bear Stearns的非存款挤兑时，美联储和美国财政部决定不再救助。Lehman Brothers于2008年9月15日申请破产。雷曼破产后，金融市场陷入恐慌。由于市场无法判断哪些金融机构能够偿还债务、哪些不能，许多金融市场在接下来数周乃至数月中事实上陷入瘫痪。世界经济陷入了自1930年代以来最严重的衰退。衰退有三个主要驱动因素。

1. 房价下跌。房屋价值下降后，家庭财富缩水，消费下降。过去一些家庭可以通过房屋净值再融资或房屋净值贷款获得额外资金，这种 **home equity release** 渠道消失了。同时，由于房价下跌，住房建设利润下降，建筑业也急剧收缩。
2. 债务危机。危机前，政府、企业和家庭都积累了较高债务。危机爆发后，这些部门不得不削减开支、降低杠杆。家庭减少消费，企业减少投资，政府可能实施财政紧缩。这些都会压低总需求。
3. 金融条件恶化。金融部门脆弱会加剧衰退。银行需要缩小资产负债表，也就是去杠杆，这导致对家庭和企业的贷款大幅下降。信贷下降又进一步压制消费和投资。

此后，全球政策态度迅速转变。各国当局认为不能再允许更多银行倒闭，否则会造成更大破坏。美国很快通过了 **Troubled Assets Relief Programme, TARP**，规模为7000亿美元，用于稳定银行体系；其他国家也出台了紧急措施。
